RECOMMENDED FIXES
==============================================================================

PRIORITY 1 - Critical (WCAG 2.1 AA Required):
1. Add prefers-reduced-motion media query support
   Location: base.html CSS section
   Code to add:
   ```css
   @media (prefers-reduced-motion: reduce) {
       *,
       *::before,
       *::after {
           animation-duration: 0.01ms !important;
           animation-iteration-count: 1 !important;
           transition-duration: 0.01ms !important;
           scroll-behavior: auto !important;
       }
   }
   ```

PRIORITY 2 - Recommended Testing:
1. Validate HTML with W3C validator (https://validator.w3.org/)
2. Test text resize to 200% zoom
3. Test reflow at 320px width
4. Test with CSS disabled for reading order
5. Test landscape/portrait orientation on mobile devices

PRIORITY 3 - Best Practices:
1. Consider adding referrerpolicy="no-referrer-when-downgrade" to all iframes
   (Already present on Google Maps iframes, add to YouTube iframes)
2. Consider adding loading="lazy" to YouTube iframes for performance
3. Document that embedded YouTube videos should have captions enabled
